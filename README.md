# Pacer releases

This repo holds the downloads for [Pacer](https://pacer.sh), the autocomplete popover for the terminal on macOS. The source code is not here.

Install with Homebrew, then run `pacer setup`:

```sh
brew install --cask alexitaylor/tap/pacer
```

Or install with the script, which also runs `pacer setup`:

```sh
curl -fsSL https://pacer.sh/install | bash
```

Pacer needs an Apple silicon Mac with macOS 13 or later, zsh, and Ghostty, iTerm2, or Terminal.
